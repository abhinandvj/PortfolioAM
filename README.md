# Abhinand VJ — Interactive Portfolio

A responsive, animated portfolio website built with plain HTML, CSS and JavaScript.

## Features
- Responsive layout
- Dark / light theme
- Scroll progress indicator
- Animated statistics
- Scroll reveal animations
- Expandable experience timeline
- Skill category filters
- Project details modal
- Copy-email interaction
- Mobile navigation
- No build step required

## Run locally
Open `index.html` in a browser.

## Deploy
This folder can be deployed directly to GitHub Pages, Netlify, Vercel, or any static hosting service.
